# block-bad-sites

![License: MIT](https://img.shields.io/github/license/ragibalasad/block-bad-sites)
 ![Python](https://img.shields.io/badge/Built%20with-Python3-3776AB)

This script allows you to block access to numerous adult websites on your device. It's designed for both Linux and Windows environments.

## 🚀 Installation

### 📋 Prerequisites
- Python 3.x installed on your system.

### 🐧 Linux
1. Download the ![repository](https://github.com/ragibalasad/block-bad-sites/archive/refs/heads/main.zip).
2. Extract the zip and open terminal in the extracted directory.
3. Run the script with:

   ```bash
   sudo python3 block.py

### 🖥️ Windows
1. ![Download](https://github.com/ragibalasad/block-bad-sites/archive/refs/heads/main.zip) and extract.
2. Run `block.py` as Administrator.
